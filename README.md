### 🔭 Featured Project: [Proxmox VE Homelab](https://github.com/abrsc/my-homelab/)
I am documenting the journey of building a realistic homelab on recycled hardware, applying enterprise-style infrastructure concepts at home.

* **Hypervisor:** Proxmox VE 9
* **Backup System:** Dedicated Proxmox Backup Server (PBS)
* **Data Safety:** Client-side backup encryption, retention policies, verification jobs & UPS power management with NUT
* **Networking & Security:** OPNsense (VLAN segmentation & Firewalling), Cloudflare Zero Trust, Nginx Proxy Manager, Wazuh SIEM, Tailscale
* **Automation:** Ansible for fleet management and deployment tasks
* **AI & Compute:** NVIDIA RTX 3060 acceleration for local LLM workloads
* **Services:** AdGuard Home, WordPress, Uptime Kuma, Ghostfolio, Ollama, Open WebUI
* **Microsoft Hybrid Lab:** Active Directory, DNS, GPO, Windows Admin Center, Hyper-V, Microsoft Entra Cloud Sync, Password Hash Sync
